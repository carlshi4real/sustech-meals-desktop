# 南科饭钱 · 桌面版

南科大校园卡消费统计与预算预测应用。界面按通用“花费”统计；学校官网成功的消费与退款默认纳入统计，可按笔或按消费地点批量调整。用户在学校官方窗口自行登录，应用不读取或保存密码，账本只留在本机。

## 使用

1. 在“预算计划”填写计划开始日、当时可用资金、期间预算、截止日和完整记账起始日。
2. 打开“校园卡导入”，在学校官方窗口登录。关闭学校窗口会自动同步；也可返回主窗口点击“一键同步账单”。
3. 在“消费账单”切换“消费流水”和“按消费地点”，核对账单、按地点批量纳入或移出统计。
4. 概览展示最近 14 天的日花费，鼠标悬停在柱形上可查看当天金额；同时显示常消费地点、预计资金可用天数、接下来每天可花金额和预计结余。

所有金额使用分为单位计算。花费日均按完整记账起始日至今的自然日计算，包含零消费日。预计可用天数为剩余资金除以日均花费，向下取整；每日可花额度同时受剩余资金和期间预算约束。记录不完整时预测可能偏高。

学校账单按交易号去重。同步时逐页读取成功消费和退款，排除充值、转账和补助；发生登录失效、分页或解析错误时不写入不完整结果。首次同步将账本绑定到校园卡账号的散列值，避免混入其他账号账单。安装包不含账号、密码或个人账单。

数据存于当前用户的 `ledger.json`，可在“预算计划”导出和恢复备份。升级应用不会清除已有账本。旧版已导入但未标为餐饮的消费仍保持原分类，可在“按消费地点”中批量纳入。

## 构建

```sh
npm ci
npm test
npm run package:mac
npm run package:windows
```

Mac 版面向 macOS 13+、Apple Silicon。Windows 版面向 Windows 10/11 x64。应用尚未使用 Apple Developer ID 签名和公证；Windows 打包产物也未做代码签名。Windows 构建可以在 Mac 上生成，但应在 Windows 设备上运行验证。
